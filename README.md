# TRPG Log Archive

Roll20 등 TRPG 채팅 로그를 **백업**하고 **시네마틱하게 감상**하는 정적 웹사이트입니다.
외부 AI API 없이, 원본 로그 HTML 파일을 브라우저 안에서 직접 읽어 블록으로 변환합니다.
모든 데이터는 이 깃허브 레포지토리(`TRPG_Log`) 안의 파일로 관리됩니다.

---

## 1. 폴더 구조

```
TRPG_Log/
├─ index.html              # 진입점
├─ css/
│  ├─ base.css             # 디자인 토큰 · 공통 · 상단 바
│  ├─ library.css          # 홈(서가) · 카드 · 장면 목차
│  ├─ editor.css           # 등록/편집기
│  └─ viewer.css           # 시네마틱 뷰어
├─ js/
│  ├─ util.js              # 공용 유틸 · 이미지 경로 · 아바타
│  ├─ parser.js            # 원본 로그 HTML 가져오기(Roll20)
│  ├─ data.js              # 데이터 로딩(manifest+세션)
│  ├─ library.js           # 홈/목차 뷰
│  ├─ viewer.js            # 뷰어 + 인라인 BGM
│  ├─ editor.js            # 등록/편집
│  └─ app.js               # 초기화/라우팅
├─ data/
│  ├─ manifest.json        # 화면에 표시할 세션 목록
│  └─ sessions/            # 세션별 JSON 파일
├─ image/                  # 캐릭터/커버 이미지
│  └─ <session_name>/<character>.png
└─ README.md
```

## 2. 배포 (GitHub Pages)

1. 이 폴더 전체를 `TRPG_Log` 레포지토리에 올립니다.
2. 레포지토리 **Settings → Pages → Branch: main / root** 로 설정합니다.
3. `https://<사용자명>.github.io/TRPG_Log/` 로 접속합니다.

> 데이터(`data/*.json`)는 `fetch` 로 읽기 때문에 **웹 서버(GitHub Pages)** 에서 동작합니다.
> 로컬에서 `index.html` 을 파일로 직접 열면 데이터 로드가 막혀 목록이 비어 보입니다.
> 로컬 확인이 필요하면 폴더에서 `python -m http.server` 후 `http://localhost:8000` 으로 여세요.

## 3. 캐릭터 / 커버 이미지 올리기

- 이미지는 `image/<세션폴더>/<파일명>.png` 형태로 올립니다. 파일·폴더 이름은 **영문/숫자**를 권장합니다.
  - 예: `image/dalde/dahlia4.png`
  - 세션 카드(썸네일)용 커버는 보통 `image/<세션폴더>/cover.png` 로 둡니다.
- Roll20 로그에 프로필 사진이 들어 있으면, 편집기 등장인물의 로그 이름 옆 **⬇** 버튼으로 내려받을 수 있습니다.
- 편집기의 캐릭터 **이미지 경로** 칸과 **세션 카드 이미지 경로** 칸에 이 경로를 그대로 적습니다.
  - `TRPG_Log/image/...` 처럼 레포명을 붙여 적어도 자동으로 정리됩니다.
- **이미지가 없는 캐릭터는 글자 없이 단색 원**으로 표시됩니다. (색상은 캐릭터 색상 사용)

## 4. 로그 등록 / 편집 → 페이지에 반영하는 흐름

1. 상단 **＋ 로그 등록** (또는 세션/장면에서 **✎ 편집**) 으로 편집기를 엽니다.
2. **세션 정보** — 기존 폴더는 드롭다운에서 고르고, 새 폴더는 옆 칸에 입력합니다.
3. **원본 로그 불러오기** — Roll20 채팅 아카이브 페이지를 저장한 **HTML 파일**을 끌어다 놓습니다.
   - 텍스트만 추출해 자동으로 블록(나레이션·대사·주사위)으로 바꿉니다. 제목·날짜가 비어 있으면 로그에서 채워집니다.
   - 숨김 처리된 메시지는 빠지고, 귓속말은 옵션으로 포함할 수 있습니다.
   - 작업하던 **세션 JSON** 파일을 넣으면 그 세션을 이어서 편집합니다.
   - 이미 로그가 있으면 **교체** 또는 **뒤에 이어 붙이기**를 고를 수 있습니다(여러 번에 나눠 저장한 로그 합치기).
4. **등장인물** — 로그에 나온 화자 이름이 자동으로 캐릭터가 됩니다.
   - 역할(PC/KPC/NPC)·색상·이미지 경로를 정합니다. **PC → 오른쪽**, **KPC·NPC → 왼쪽** 말풍선.
   - 같은 캐릭터가 다른 이름으로 나왔다면(예: `???` → `미뉴에트`) 로그 이름 옆 **옮기기**로 한 캐릭터에 묶습니다.
   - **대표 이름으로 통일해 표시**를 켜면 뷰어에서 대표 이름으로, 끄면 로그에 적힌 이름 그대로 보입니다.
   - GM이 캐릭터 이름으로 서술한 경우 **☰** 버튼으로 그 캐릭터의 대사를 모두 나레이션으로 바꿀 수 있습니다.
5. **로그 다듬기**
   - 블록 사이 **＋** : 장면 나누기 · BGM · 핸드아웃 · 나레이션 · 대사 · 주사위 삽입
   - 블록의 **✂** : 그 블록부터 새 장면 시작 / **⤒** : 위 블록과 합치기 / **↑↓** : 이동 / **✕** : 삭제
   - 글자를 눌러 바로 수정(오타 수정), 상단 **B · I** 로 굵게·기울임
   - 체크박스 선택 후 **Shift+클릭**으로 범위 선택 → 한꺼번에 삭제·합치기·나레이션 변환
   - **↶ 되돌리기**(Ctrl+Z)로 직전 작업 취소, 장면 구분의 **▶ 미리보기**로 뷰어 확인(Esc로 복귀)
6. **⬇ 세션 JSON 다운로드** → `data/sessions/` 에 올리고 `data/manifest.json` 목록에 경로를 추가합니다.

```json
{
  "sessions": [
    "data/sessions/dalde_lampion4.json"
  ]
}
```

7. 커밋하면 GitHub Pages 배포 후 새로고침 시 반영됩니다.

## 5. 로그 변환 규칙 (Roll20)

| 원본 | 변환 결과 |
|---|---|
| 화자 이름이 있는 메시지 | 새 블록 시작 (이름이 없는 다음 메시지들은 같은 화자로 이어짐) |
| 화자 이름이 비었거나 `(GM)` 포함 | 일반 나레이션 |
| `/desc` 장면 설명 | 강조 나레이션 (연속되면 한 블록) |
| 대사 메시지 | 따옴표 안 = 대사, 밖 = 지문 (볼드·기울임 유지) |
| 크툴루 판정 템플릿 | 주사위(기준치): 판정명·등급·기준치·굴림·판정결과 |
| 표 형식 판정(기준치/굴림/판정결과/피해) | 주사위(기준치 또는 공격) |
| 인라인 굴림만 있는 메시지 (`1d3`) | 주사위(단순 굴림) |

- 판정명은 바로 앞의 `관찰력 판정` 같은 안내 문구가 있으면 그 이름을, 없으면 영문 기술명을 한글로 바꿔 씁니다.
- 코코포리아 로그는 추후 지원 예정입니다.

## 6. 뷰어 사용

- 세션 카드를 누르면 **장면 목차**가 뜨고, 장면을 고르면 시네마틱 뷰어가 열립니다.
- **BGM 블록**은 로그 중간에 놓이며, 독자가 직접 ▶ 를 눌러 재생합니다.
  - 자동 반복되며, 다른 BGM 블록을 누르면 이전 곡이 페이드아웃된 뒤 새 곡이 재생됩니다.
- 우상단 **◑** 로 라이트/다크 테마를 전환할 수 있습니다.

> 폰트(Noto Serif KR / Pretendard)와 유튜브 BGM은 인터넷 연결이 있어야 로드됩니다.
> 브라우저 자동재생 정책상 BGM은 ▶ 를 한 번 눌러 시작합니다.
